# Игротека

[![CI](https://github.com/webwayne88/ad-free-puzzles/actions/workflows/ci.yml/badge.svg)](https://github.com/webwayne88/ad-free-puzzles/actions/workflows/ci.yml)

Головоломки без рекламы. PWA: ставится на Android с главного экрана и работает офлайн. Внутри судоку, Ballz и «Оттенки».

## Судоку

- Четыре уровня. Сложность определяется не числом открытых цифр, а тем, какие техники нужны для решения:
  - **Лёгкий** — только одиночки, 36+ открытых цифр;
  - **Средний** — только одиночки, около 30 открытых;
  - **Сложный** — нужны блокировки или пары;
  - **Эксперт** — тройки, X-wing, Y-wing, swordfish.
- Банк из 800 головоломок с единственным решением и симметричной расстановкой. При каждом запуске головоломка перемешивается (строки, столбцы, цифры), поэтому повторов на практике нет, а сложность не меняется.
- Черновик: цифру, которая уже есть в строке, столбце или блоке, пометить нельзя — она красная. Режим «Варианты» на время показывает все возможные цифры во всех пустых клетках, ручные пометки при этом сохраняются.
- Автоудаление пометок, отмена, 3 подсказки за партию, лимит в 3 ошибки со вторым шансом.
- Пауза, автопауза при сворачивании, сохранение партии, рекорды по уровням.
- Светлая и тёмная темы. На широком экране поле слева, панель управления справа.
- Клавиатура: `1–9`, стрелки, `Backspace`, `N` — черновик, `H` — подсказка, `A` — варианты, `Space` — пауза, `Ctrl/Cmd+Z` — отмена.

## Ballz

- Потяни вниз и отпусти: шары вылетают очередью, каждое попадание снимает с блока единицу. Кольцо роняет вниз шар другого цвета: он ждёт на полу, пока все вернутся, потом катится к точке запуска и со следующего хода играет как обычный. Блок дошёл до низа — конец игры; когда блок стоит на последнем ряду, рамка поля мягко светится красным.
- Новый ряд появляется на каждом уровне. С 10-го уровня часть блоков удвоенная, ряды становятся плотнее.
- Цвет блока зависит от его числа относительно уровня: фиолетовый — удвоенный, бирюзовый — свежий, синий, малиновый, коралловый — почти разбит.
- Затянувшийся ход ускоряется сам, а кнопка «Ускорить ×4» видна весь ход: шары долетают быстрее, все попадания засчитываются. Шар не может бесконечно летать горизонтально.
- Позиция сохраняется на начало хода, рекорд — отдельно. Светлая и тёмная темы — общие с приложением.
- Клавиатура: `←/→` — прицел, `Enter`/`Space` — выстрел, `↓` — ускорить, `Esc` — пауза.

## Оттенки

- **Запомни цвет**: цвет показывается 3 секунды, потом восстанавливаешь его ползунками «тон, насыщенность, яркость».
- **Допиши палитру**: гармоничная палитра с пустым местом — комплементарная, аналоговая, триада, сплит-комплементарная, квадрат или монохромная. За партию все гармонии разные; после ответа — идеальный цвет и правило гармонии.
- 5 раундов по 10 очков. Точность считается в OKLab, близком к восприятию; подсказка («темнее, чем нужно», «слишком блёклый») — в терминах ползунков.
- Рекорды по каждому режиму. Ползунки свои, с клавиатурой: стрелки, `PageUp/PageDown`, `Enter` — ответить.

## Запуск

```bash
cp .env.example .env
docker compose up -d --build web
```

Открыть: http://localhost:8080 (порт задаётся в `.env`, переменная `WEB_PORT`).

С телефона в той же сети: `http://<IP мака>:8080`. Офлайн-режим и установка на главный экран требуют HTTPS — для этого есть версия на GitHub Pages (ниже).

## Деплой

Сайт: https://webwayne88.github.io/ad-free-puzzles/

`.github/workflows/ci.yml` на каждый пуш в `main`/`dev` и на PR гоняет тесты. Из `main` при зелёных тестах выкладывает на GitHub Pages только файлы приложения и меняет имя офлайн-кеша на хеш коммита — телефоны сразу получают новую версию.

## Тесты и генерация банка

```bash
docker compose run --rm tools node --test
docker compose run --rm tools node tools/generate-sudoku.js 200 20261010   # штук на уровень, seed
```

## Структура

```
js/sudoku/engine.js   решатель, генератор, оценка сложности, перестановки
js/sudoku/game.js     состояние партии: ходы, ошибки, пометки, отмена, подсказки
js/sudoku/session.js  банк, сохранение, статистика
js/sudoku/view.js     экран игры
js/ballz/engine.js    физика Ballz: шары, столкновения, ряды, кольца
js/ballz/view.js      экран Ballz на canvas
js/hues/color.js      HSV, OKLab, очки и подсказки
js/hues/harmony.js    гармонии цветового круга
js/hues/picker.js     ползунки выбора цвета
js/ui.js              шторки, диалоги, переключатели
data/sudoku.json      банк головоломок
tools/                генератор банка
tests/                node:test
```

Иконки интерфейса основаны на [Lucide](https://lucide.dev) (ISC).
